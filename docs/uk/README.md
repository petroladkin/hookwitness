# Документація Hookwitness

Ловіть вебхуки, отримуйте вердикт, додавайте докази. Ці сторінки вчать
працювати з Hookwitness за задачами: що натиснути і що станеться.
[English](../README.md).

Назви кнопок і вкладок подано англійською, як в інтерфейсі.

1. [Перші кроки](getting-started.md): запустити, створити ендпоінт, надіслати
   вебхук, прочитати його.
2. [Ендпоінти й живий перегляд](endpoints.md): точні шляхи, реєстр Unmatched,
   реєстр і його стрічка, запит повністю, повтори.
3. [Сценарії відповідей](replies.md): правила (кожен N-й, перші N, випадково),
   затримки, таймаути, обірвані з'єднання, шаблони, обов'язкові заголовки.
4. [Перевірки автентичності й секрети](authorization.md): GitHub, Stripe,
   Standard Webhooks, довільний HMAC, bearer, basic; примусова відмова;
   секрети лише на запис.
5. [Перевірки JSON Schema](schemas.md): одна схема, будь-яка з кількох або
   вибрана за значенням; чернетки з упійманих тіл; зображення в даних.
6. [Звіти](reports.md): докази у Markdown, HTML і PDF для тікета; маскування.
7. [Налаштування й розгортання](deployment.md): Docker і його том,
   параметри, ключ секретів, зворотні проксі.
8. [Розв'язання проблем](troubleshooting.md): секрет є, а вердикту нема;
   відмова за іменем хоста; секрети не читаються; 413; втрачені дані.
9. [Тестування відправника з AI-агентом](agents.md): skill для Claude Code.

Довідник: [REST API](../api.md) (лише англійською) та його опис OpenAPI 3.1
за адресою `/admin/api/v1/openapi.json`.
